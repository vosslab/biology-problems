YAML ordering banks generate sequence multiple-choice questions and native draggable ORDER questions. The authoring guide explains bank structure, generation, labels, colors, and molecular structures.

## Question formats

- SEQUENCEMC shows four complete sequences. Generated label and prose colors follow shuffled display positions, so colors stay consistent across choices without revealing the correct sequence.
- Native ORDER keeps its existing presentation. Students move the actual step text, which reduces the need for color cues. The learning management system controls the initial shuffle, so the generator cannot set its display order.

Rainbow colors tied to correct ranks would reveal the answer. If automatic color is added to native ORDER later, choose colors randomly and independently of correct ranks for each question, then attach each color to its step while it is dragged. Existing meaningful colors authored through `replacement_rules` remain available.

See [ORDERING_AUTHORING_GUIDE.md](ORDERING_AUTHORING_GUIDE.md) for bank format and generation details.
