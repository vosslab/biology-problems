# Repository color assignments

Choose colors from [COLOR_PALETTE.md](COLOR_PALETTE.md) and use these assignments for the local
materials named below. Reuse each assignment in related figures, labels, tables, and explanations.

## Chromosome alterations

Use the full alteration names in questions and explanations. Color the name for the alteration
type and use the chromosome fills to identify the source material.

| Alteration | Text |
| --- | --- |
| Deletion | Pink Dark |
| Duplication | Green Dark |
| Inversion | Light orange Dark |
| Translocation | Navy Dark |

## Three-point testcross pairs

Use each pair's recombinant color for its rows, labels, map lines, results, and final percentage.
Use the listed fills in tables and allele comparisons. Keep the covered gene column gray even
where it crosses highlighted rows. Preserve the timing of classification and result reveals.

| Meaning | Labels and lines | Fill |
| --- | --- | --- |
| Original parental rows | Green Dark | Green Light |
| Other offspring parental for the selected pair | Lime green Dark | Lime green Extra light |
| CD recombinants and results | Red Dark | Red Light |
| CH recombinants and results | Blue Dark | Blue Light |
| DH recombinants and results | Purple Dark | Purple Light |

For reproduction, older examples use fills `#8FFF8F`, `#D6FFAD`, `#FF8F8F`, `#8FABFF`, and
`#DC9AF4`, in table order. The covered gene column keeps its neutral fill.

## Procedure sequences

For four steps, use Red, Green, Blue, and Purple. For six, use Red, Dark orange, Dark yellow,
Green, Blue, and Purple. Use the Dark shades. Repeat each roadmap with the same assignments and
match cross-references to its steps. Track roadmap steps and data classes by their own keys.

For other lengths up to 14, spread the choices across the ordered hue families, including the
first and last. For longer sequences, repeat the sequence and retain visible step labels.
In randomized ordering questions, assign colors to the displayed choices after shuffling so
the colors follow display order.

## Visual translocation questions

Track each chromosome fragment through the originals and every answer choice. Use Light fills
from four distinct families and gray telomere caps. Keep the gene sequence and exchange junctions
visible. The current visual letter-translocation generator samples four distinct light fills
from the QPM color wheel.
